# 工程系統功能分析與修剪技術 (Function Analysis & Trimming Guide)

功能分析（Function Analysis）與修剪（Trimming）是現代實戰 TRIZ（如 Altshuller Institute 及 Oxford Creativity 體系）中工程師最核心、產出效益最直接的工具。

---

## 1. 工程功能建模標準 (Function Modeling)

### 功能三要素標準定義
一個精確的功能描述必須符合標準語法：
$$\text{Subject (主體/載體)} \xrightarrow{\quad \text{Action (動作/作用)} \quad} \text{Object (客體/受體)}$$

- **主體 (Subject)**：執行動作的實體組件（名詞）。
- **動作 (Action)**：改變或維持客體狀態的物理/化學過程（及物動詞，如：加熱、支撐、夾緊、導向、阻擋、傳遞；避免使用非物理動詞如「通知」、「協助」）。
- **客體 (Object)**：被作用的實體組件或材料（名詞）。

### 功能的四種性質標記
- **有用且充分 (Useful & Adequate)**：符合設計要求的正常功能（綠色實線箭頭）。
- **有用但過度 (Useful but Excessive)**：作用強度超出必要需求，造成浪費或損耗（黃色箭頭）。
- **有用但不足 (Useful but Insufficient)**：作用強度未達設計標準（黃色虛線箭頭）。
- **有害功能 (Harmful)**：伴隨產生的負面作用，如磨損、過熱、腐蝕、噪音（紅色波浪箭頭）。

## 2. 系統修剪技術三條黃金法則 (3 Trimming Rules)

修剪的目的是精簡結構、降低成本並消除有害功能，逼近最終理想解 (IFR)。

```
                  ┌─────────────────────────────────┐
                  │ 欲修剪之組件 (Target Component) │
                  └───────────────┬─────────────────┘
                                  │
      ┌───────────────────────────┼───────────────────────────┐
      ▼                           ▼                           ▼
  【規則 A: 刪除客體】        【規則 B: 客體自我執行】      【規則 C: 轉移至其他組件】
若該組件作用的客體已不存在    讓客體或環境自身承擔該功能    由系統內其餘組件或超系統
則該組件可直接安全刪除。      （應用自助或自修復原理）。    承擔該功能（多功能化）。
```

### 規則 A：客體消失 (The Object is eliminated)
- 如果系統不再需要處理該客體，則負責該功能的組件可被直接刪除。
- *範例*：採用無線資料傳輸後，實體訊號傳輸線與線夾組件可直接修剪。

### 規則 B：客體自我服務 (The Object performs the function itself)
- 讓被作用的客體自身執行該動作。
- *範例*：用自攻螺絲（客體自身切削螺紋）修剪掉專門的攻牙刀具。

### 規則 C：功能轉移 (Another component performs the function)
- 將被修剪組件的有用功能，轉移給系統內現有的另一個組件或超系統/環境承擔。
- *範例*：將筆電的專用散熱支架功能轉移給筆電底殼一體成型的傾斜防滑腳墊。
