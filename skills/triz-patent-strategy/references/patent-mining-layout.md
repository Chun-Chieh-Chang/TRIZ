# 專利探勘與 TRIZ+ 專利布局策略 (Patent Mining & Strategic Layout)

專利布局是將單一技術點擴展為立體專利防護網的戰略過程。透過 TRIZ+ 理論與技術進化樹，可以在競爭對手申請專利之前，預先搶佔未來所有可能的技術演進路線。

---

## 1. TRIZ+ 專利探勘與演化路徑挖掘 (Evolutionary Patent Mining)

利用 TRIZ 的 **進化路線 (Evolution Lines)**，從當前核心專利出發，沿著特定維度預先生成未來專利族：

1. **結構動態化進化線**：
   - 剛性單體 → 單處鉸接 → 多處鉸接 → 柔性彈性體 → 液體/氣體填充 → 磁場控制
   - *布局動作*：圍繞核心剛性專利，同時申請鉸接式、柔性彈性結構及氣動/磁控替代方案專利。
2. **表面幾何演化線**：
   - 平面 → 凹凸曲面 → 帶微孔表面 → 仿生微奈米結構 → 動態可調幾何
3. **物質相態演化線**：
   - 單一固體材料 → 多孔材料 → 相變材料 (PCM) → 奈米複合材料

## 2. 三大經典專利布局戰略 (Patent Layout Strategies)

```
        【包夾布局】                    【路障布局】                    【網狀布局】
     ┌───┐ ┌───┐ ┌───┐                                          ●───●───●
     │專 │ │專 │ │專 │                                          │ ╲ │ ╱ │
     └───┘ └───┘ └───┘              ══════[ 核心咽喉 ]══════      ●───●───●
  ┌───┐ ┌─────────┐ ┌───┐             （卡死必經之路）           │ ╱ │ ╲ │
  │專 │ │對手專利 │ │專 │                                          ●───●───●
  └───┘ └─────────┘ └───┘
     ┌───┐ ┌───┐ ┌───┐
     │專 │ │專 │ │專 │
     └───┘ └───┘ └───┘
```

### 1. 包夾戰略（圍欄式布局，Picket Fence / Encirclement）
- **應用場景**：競爭對手已搶先獲得某項核心基礎專利。
- **布局操作**：
  - 圍繞該基礎專利的「所有商業應用場景」、「上下游接口」、「改良工藝」與「周邊輔助模組」大量申請外圍專利。
  - 對手雖有核心專利，但無法單獨將產品商業化落地（落地必踩我方外圍專利），迫使其交叉授權或進行專利和解。

### 2. 路障戰略（阻斷式布局，Roadblock / Choke Point）
- **應用場景**：發現技術發展的必經咽喉要道。
- **布局操作**：
  - 利用 TRIZ 進化趨勢預測出該行業未來 3~5 年必然採用的最佳幾何形態或物理原理。
  - 在核心演進節點精準部署 1~2 篇權利範圍極寬的基礎專利，封死對手升級路徑。

### 3. 網狀防禦戰略（地雷陣布局，Patent Network）
- **應用場景**：建立自身產品的護城河。
- **布局操作**：
  - 將產品從零件製造、組裝工藝、控制演算法、外觀設計到檢測維護，進行立體多層次交叉申請，構建無死角防禦網。
