# TRIZ 專利迴避設計實戰手冊 (TRIZ Patent Circumvention & Design-Around)

專利迴避設計（Design-Around）是在不侵害競爭對手既有專利獨立項（All-Elements Rule 全要件原則）的前提下，透過技術創新開發出可商業化的替代技術方案。

---

## 1. 專利侵權判斷原則與迴避切入點

### 全要件原則 (All-Elements Rule)
若目標專利獨立項請求項包含技術特徵：$A + B + C + D$
- **字面侵權 (Literal Infringement)**：被控方案具備 $A + B + C + D$（甚至包含 $E$），即構成侵權。
- **不侵權標準**：若被控方案缺少其中任一必要技術特徵（例如僅具備 $A + B + C$），且該特徵未被均等置換，則不構成侵權。

### 均等論 (Doctrine of Equivalents)
- **Triple Identity Test（三實質原則）**：若替代特徵以「實質相同的方式 (Way)」、「執行實質相同的功能 (Function)」、「達成實質相同的結果 (Result)」，且為該領域通常知識者顯而易知，仍可能構成均等侵權。
- **TRIZ 迴避目標**：必須透過原理級或架構級的根本創新，打破 Way 或 Function，徹底跳出均等論範圍。

---

## 2. TRIZ 專利迴避四大核心策略 (4 Circumvention Strategies)

### 策略一：元件修剪與功能轉移法 (Trimming & Function Redistribution)
- **目標**：徹底刪除專利請求項中的某一必要特徵（如刪除特徵 $D$）。
- **TRIZ 操作**：
  1. 識別特徵 $D$ 在原系統中提供的有用功能 $F_D$。
  2. 將 $F_D$ 轉移給剩餘元件（$A$、$B$ 或 $C$）承擔（應用 #6 多功能原理或 #25 自助原理）。
  3. 或者將 $F_D$ 轉移給超系統/環境免費承擔。
  4. 完全移除實體元件 $D$，達成合法避開全要件限制。

### 策略二：根本原理替代法 (Physics/Field Substitution)
- **目標**：打破「相同方式 (Way)」，使均等論不成立。
- **TRIZ 操作**：
  - 應用 #28 機械系統替代原理：若原專利採用「機械接觸式傳動與定位」，新方案改用「光學感應」或「電磁力懸浮控制」。
  - 運行原理與技術手段產生跨領域躍遷，法院認定為非均等替代。

### 策略三：向超系統或微觀層級躍遷法 (System Transition)
- **目標**：跳出原專利的宏觀結構定義。
- **TRIZ 操作**：
  - 將原專利的固定幾何結構改為微觀孔隙結構（#31 多孔材料）或智慧相變材料（#36 相變原理）。

### 策略四：反向操作與時空分離 (Inverse & Dynamic Transformation)
- **目標**：改變運動關係與運作時序。
- **TRIZ 操作**：
  - 應用 #13 反向運作（如原專利旋轉外筒，新方案改為旋轉內軸並固定外筒）。
