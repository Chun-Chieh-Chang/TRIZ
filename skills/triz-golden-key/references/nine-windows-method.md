# 九屏幕法（九宮格思維）與資源探勘 (Nine Windows Method & Resources)

九屏幕法（又稱九宮格思維法、系統算子）是 TRIZ 中用來克服「點狀思維」與打破「思維慣性」的核心多維視野工具。

---

## 1. 九屏幕矩陣結構 (The 3x3 Matrix)

透過「時間維度」（過去、現在、未來）與「空間/系統層級維度」（超系統、當前系統、子系統）構建的 3x3 視圖：

| 系統層級 \ 時間維度 | 過去 (Past) | 現在 (Present) | 未來 (Future) |
| :--- | :--- | :--- | :--- |
| **超系統 (Super-system)** | 過去的外部環境、使用場景、上下游產業 | **現在的外部環境、法規、使用者、互補產品** | 未來的生態系、智慧環境、新標準 |
| **當前系統 (System)** | 系統的前身、傳統產品型態 | **當前研究的核心產品 / 技術對象** | 下一代產品、終極理想解 (IFR) |
| **子系統 (Sub-system)** | 過去的材料、零件、動力機制 | **現在的內部零組件、微觀結構、能量場** | 未來的奈米結構、智慧材料、量子效應 |

---

## 2. 九屏幕法標準操作步驟

1. **鎖定中央格（現在的當前系統）**：明確寫下當前需要解決問題的具體產品或工藝。
2. **向下探勘子系統（現在的子系統）**：拆解其內部結構、材料屬性、電磁熱力狀態，尋找可動用的內部資源。
3. **向上擴展超系統（現在的超系統）**：審視其所處的物理環境、使用者行為、周遭廢熱或重力場等免費資源。
4. **向左追溯歷史（過去的三格）**：分析過去系統是如何運作的？產生當前問題的前置條件是什麼？能否在過去的階段預先干預？
5. **向右展望未來（未來的三格）**：預測工作完成後系統的狀態、廢棄處置、或下一代演進方向。

---

## 3. 資源探勘分類清單 (Resource Checklist)

在九個屏幕中全面搜檢以下 6 大類免費或廉價資源：
1. **物質資源 (Substance)**：系統廢料、包裝材料、環境空氣、水、微量雜質、邊角料。
2. **能量場資源 (Field/Energy)**：機械振動、重力、摩擦熱、環境光、電磁輻射、氣壓差。
3. **空間資源 (Space)**：未利用的空腔、夾層、表面積、微觀孔隙、垂直空間。
4. **時間資源 (Time)**：兩次操作之間的空檔期、預熱時間、冷卻時間、夜間閒置期。
5. **功能資源 (Function)**：已有部件閒置未用之副產功能、反向功能。
6. **資訊資源 (Information)**：系統自然發出的聲音、溫度變化、顏色轉變、振動頻率信號。
