# TRIZ 智慧問題診斷與方法論路由矩陣 (Methodology Routing Matrix)

本矩陣提供架構師與工程師在面對不同研發情境、專利攻防、成本優化或前瞻預測時的精確導航指引。

---

## 研發情境與對應 Skill 路由表

| 當前情境 / 核心挑戰 | 典型問題特徵 | 推薦進入的專題 Skill | 核心調用工具 / 方法 |
| :--- | :--- | :--- | :--- |
| **兩難折衷 / 參數衝突** | 想提升速度但能耗暴增；想增強強度但重量超標 | [triz-contradiction-matrix](../triz-contradiction-matrix/) | 39 工程參數對照、矛盾矩陣查表、發明原理推薦 |
| **需要跨界/軟體/商業創新** | 軟體架構瓶頸、業務流程優化、服務體驗升級 | [triz-40-principles-extended](../triz-40-principles-extended/) | 擴展版 40 發明原理、跨學科類比啟發 |
| **深層極端物理衝突** | 同一零件既要高溫又要低溫；既要剛硬又要柔軟 | [triz-inventive-problem-solving](../triz-inventive-problem-solving/) | 四大分離原理（空間/時間/條件/系統層次分離） |
| **專利侵權風險 / 專利戰略** | 對手專利卡位需要迴避；預先布局下一代專利網 | [triz-patent-strategy](../triz-patent-strategy/) | 專利請求項拆解、修剪法迴避、包夾/路障布局 |
| **結構複雜 / 成本過高 / 故障** | 零組件過多需要精簡；產品出現不明故障或缺陷 | [triz-for-engineers](../triz-for-engineers/) | 功能分析模型 (FA)、三條修剪法則 (Trimming)、因果鏈 (RCA+) |
| **重大技術瓶頸 / 無現成解** | 常規方法全部失效；需要追求最終理想解 (IFR) | [triz-innovation-algorithm](../triz-innovation-algorithm/) | ARIZ-85C 九階段演算法、物質-場模型、76 標準解 |
| **產品代際規劃 / 趨勢預測** | 想知道下一代產品怎麼演進；打破點狀思維 | [triz-golden-key](../triz-golden-key/) | 8 大技術系統進化法則、S 曲線、九屏幕法 |
| **快速頭腦風暴 / 尋找靈感** | 需要全景式創意激盪與原理啟發 | [triz-40-principles](../triz-40-principles/) | 40 條經典發明原理與子條款手冊 |
